# Nanuly Works

Portfolio and works showcase website built with Jekyll and hosted on GitHub Pages.

## About

This repository contains the source code for Nanuly's portfolio website, showcasing various projects and works.

## Local Development

To run this site locally:

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000` in your browser.

## Deployment

This site is automatically deployed to GitHub Pages when changes are pushed to the main branch.
